# Out's Custom Quick Access Bubbles

A Mod for A Township Tale that customize quick-access bubbles.

- Separate outer, inner, and icon colors per bubble
- Adjust bubble sizes
- Six profiles and Bubble "Share codes" to show others your custom bubble
- Social Tablet UI (requires TabletUILib both PC & Quest) https://github.com/SmoothieBrain/TabletUILib/releases/tag/v1.2.0
- Scan for bubbles for when some options don't appear

"Share codes" keep colors only (four bits per channel); they do not include sizes.

## Not included

Game files, the APK, generated game assemblies, MelonLoader, and TabletUILib are not distributed here. Obtain them from their original sources.
